# Catering Control Room

Catering management app: stock, menu costing, events and sales, staff and HR, expenses, profit and loss, and growth insights.

It is hosted on GitHub Pages. Records are stored in Google Firebase (Firestore), and users sign in with Google. Only the accounts listed in `firestore.rules`, as published in the Firebase console, can read or write records.

Setup steps are in GITHUB-FIREBASE-SETUP.md, which came with the zip.
